# Sistema de Estoque com Flet 📦

Este é um projeto pessoal de um sistema de cadastro de produtos utilizando uma interface gráfica feita em Python com a biblioteca **Flet** e banco de dados **MySQL**.

## Como rodar o projeto no seu computador

### 1. Requisitos
Você precisa ter o Python e o MySQL instalados na sua máquina.

### 2. Instalar as bibliotecas
Abra o terminal na pasta do projeto e instale as dependências:
```bash
pip install flet mysql-connector-python python-dotenv
